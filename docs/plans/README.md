## Software

The kind software you write for hardware is often called *embedded software*, from the perspective of the programmer hardware is often call *embedded systems*. These terms don't cover the scope what modern hardware product well.

### This is my understanding of embedded systems

Embedded Software is often written for 2 contexts *bare metal* and *operating systems*:
- *bare metal* - software written that directly controls hardware.
- *operating system* - software with structured access to the hardware.

In *bare metal* programming you compose *abstractions* over *hardware* to build applications.
- *hardware* - the device(s) executing your program(s), and all functionality exposed to them.
- *abstractions* - logic invented to make working with something easier.

For *operating system* based programming I don't <u>YET</u> have a smooth description.
